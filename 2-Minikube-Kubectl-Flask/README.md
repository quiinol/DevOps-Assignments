# Assignment 2: Deploy a Flask App on Minikube Using kubectl and YAML

## Objective
Deploy a Python Flask web application on a local Kubernetes cluster using Minikube, Docker, kubectl, and a YAML configuration file.

## Tools and Technologies
- Python 3.8
- Flask
- Docker
- Kubernetes
- Minikube
- kubectl
- Ubuntu on WSL
- Git and GitHub

## Application Overview
The Flask application handles requests to the home route (`/`) and returns:

`Hello from Flask on Kubernetes!`

The application listens on port `15000`.

## Project Files
- `app.py` — Flask application code.
- `Dockerfile` — instructions to build the Docker image.
- `flask-deployment.yaml` — Kubernetes Deployment and Service configurations.
- `screenshots/` — screenshots showing deployment and successful access.

## Implementation Steps

### 1. Create the Flask application
Created `app.py` using Flask. The application listens on `0.0.0.0:15000`.

### 2. Create the Docker image
Created a Dockerfile using the `python:3.8-slim` base image and installed Flask.

Built the image:

```bash
docker build -t flask-app:latest .
```

### 3. Load the image into Minikube
Minikube uses the containerd runtime, so the locally built image was loaded into Minikube:

```bash
minikube image load flask-app:latest
minikube image ls
```

### 4. Deploy the application
Created `flask-deployment.yaml` with a Deployment named `flask-app`, one replica, and `imagePullPolicy: Never`.

Applied the configuration:

```bash
kubectl apply -f flask-deployment.yaml
```

### 5. Verify the Deployment and Pod

```bash
kubectl get deployments
kubectl get pods -l app=flask-app
kubectl describe deployment flask-app
kubectl logs flask-app-59f7cdccb4-h9829
```

The Deployment showed one available replica, and the Pod was in the `Running` state.

### 6. Create the Kubernetes Service
Added a NodePort Service named `flask-app-service` to the YAML file. It selects Pods labelled `app: flask-app` and forwards traffic to port `15000`.

Applied and verified the Service:

```bash
kubectl apply -f flask-deployment.yaml
kubectl get services
kubectl get endpoints flask-app-service
```

### 7. Access and test the application
Obtained the Minikube service URL:

```bash
minikube service flask-app-service --url
```

Tested the generated URL from PowerShell using:

```powershell
Invoke-WebRequest -Uri "http://127.0.0.1:43523" -UseBasicParsing
```

The actual URL was generated by Minikube and may differ on another run.

## Results
- Docker image `flask-app:latest` built successfully.
- The image was available inside Minikube.
- The Deployment had one available replica.
- The Flask Pod was running with zero restarts.
- The Service had an endpoint pointing to the Flask Pod on port `15000`.
- The HTTP request returned status code `200 OK`.
- The application returned `Hello from Flask on Kubernetes!`.

## Conclusion
Successfully deployed and tested a Python Flask application on a local Kubernetes cluster using Minikube, Docker, kubectl, and YAML. This exercise demonstrated container image creation, Kubernetes Deployments, Pods, Services, and service access.
